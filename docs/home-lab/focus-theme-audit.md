## 交互与几何修复

- 专注卡片按小/中/大尺寸使用固定内容框；标题单行省略，中/大尺寸说明保留两行，缺少说明也不会改变卡片高度。
- 悬停或键盘聚焦通过独立浮层显示完整说明，保持网格不移动；修复旧主题隐藏说明浮层的问题。
- 说明按钮位于链接之外；手机点击后使用原生 dialog 查看全文，关闭/取消返回按钮，点击说明不打开网站。
- 分类入口补充键盘 Enter/Space 操作及选中状态。
