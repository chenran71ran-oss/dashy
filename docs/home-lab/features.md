# 功能与运行边界

[文档首页](../readme.md) · [部署](deployment.md) · [使用](usage.md)

界面存在选项、组件可配置和数据源已可用，是不同的事情。

| 能力 | 当前实现 | 条件 |
| --- | --- | --- |
| 分类、小分类、搜索、打开方式 | 保留并适配 | 自己的网站配置 |
| 总站、专注、工作台 | 三视图可用 | iframe 需目标站允许 |
| 主题、中文标注、机甲、收藏 | 定制界面；收藏经 KV 同步 | 云端登录与 KV |
| YAML、多页面 | 编辑、导入导出；页面独立存储 | 云端保存 |
| 配置历史 | 保存前备份上一版 | 最多 20 条目录记录，内容 30 天 |
| 图标读取与图标包 | 路径、相对地址、清单与品牌回退 | 公开 HTTPS 资源 |
| HTTP 检测 | Worker 检查响应与重定向 | 公开可达目标 |
| ICMP Ping | 后端转发与配置提示 | 支持 `/ping-check` 的主机后端 |
| 系统信息 | 后端转发 | 支持 `/system-info` 的主机后端 |
| 忽略 TLS 错误 | 交由兼容后端 | 可选后端，Worker 不直接跳过验证 |
| 内网探测 | 浏览器侧能力保留 | 当前网络和浏览器允许访问 |
| 上游 94 种小组件及别名 | 目录和配置入口恢复 | 各组件的服务、授权和兼容 API |
| RSS、日历、公共 API 与代理 | Worker 适配 | 接口格式及授权 |
| 天气 | OpenWeather，城市/坐标、一位小数 | API Key 与数据源 |
| PWA | 按 `enableServiceWorker` 开启 | 支持的浏览器，私有配置/API 不进 SW 缓存 |

## 与上游的区别

默认后端是 Worker，未自动运行原版 Node/Express 服务。Docker、SSO、主机信息和其他服务端选项必须结合部署方式阅读。

当前管理员登录使用 `ADMIN_TOKEN`，不能假定完整支持上游所有登录提供方。可选后端配置见 [恢复技术记录](../home-lab-feature-restoration.md)。

当前不承诺后台持续 24 小时监控、自动创建外部监控服务、绕过登录或 iframe 限制，也不声称所有浏览器/主题/API 组合均已逐项实测。

网站说明可手动编辑，目前没有统一自动摘要功能。后续合并上游应保留前端定制，逐项核对功能和配置，不直接覆盖整个 fork。
