# Brog Hub icon

The owner-provided artwork is bundled at `/portal-icons/brog-hub.svg` and available as `portal-brog-hub` in the icon picker.

The SVG embeds the original 1179 × 1168 JPEG bytes without recompression or upscaling. A 164-unit corner radius clips the image at display time; the composition and original pixels are retained. No remote image host or favicon proxy is required.

Only the exact blog host and the `Brog Hub` name match this catalog entry. The temporary `lucide-book` placeholder for this entry resolves to the new artwork; other custom icon choices remain unchanged. This does not write or publish the private cloud configuration.
