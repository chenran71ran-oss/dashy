# 使用 Home Lab

[文档首页](../readme.md) · [功能边界](features.md) · [FAQ](faq.md)

## 管理入口

进入编辑模式，在分类下添加网站，填写名称、完整网址、图标和可选说明。外部网站与自己的 Worker 分站都可添加。小分类用于在分类内组织一组入口。

高级选项保留状态检测、内网地址、别名、快捷键及原版字段。只开启需要的选项。表单 **保存** 后检查预览，再点击 **保存到云端**；其他设备刷新读取同一配置。

## 三视图

| 视图 | 用法 |
| --- | --- |
| 总站 | 查看分类与组件，选择布局和卡片尺寸 |
| 专注 | 在分类标签间切换，展示当前分类的网站与组件，搜索可跨分类 |
| 工作台 | 侧栏选择网站或组件，在右侧工作区域查看；多任务行为遵循配置 |

专注是分类聚焦视图，没有内置番茄钟，也不会屏蔽其他网站。网站打开方式优先于当前视图；选择 **工作台内打开** 才会尝试 iframe，目标拒绝嵌入时改为新标签页。

## 图标

| 方式 | 行为 |
| --- | --- |
| 自动匹配 | 优先 QX/品牌目录，再读取公开首页，最后尝试 favicon；失败显示首字占位 |
| 读取当前网站图标 | 主动读取当前路径的公开元数据，移除查询参数和片段，支持相对地址、base 与 PWA 清单 |
| 选择图标 | 品牌、用途分类、彩色 SVG、emoji 等 |
| 图片地址 | 使用有权使用的 URL 或本站资源路径 |

读取结果写入草稿，保存到云端才持久化。失败保留原图标。公开抓取检查域名、重定向、图片格式与大小，不转发总站 Cookie 或第三方登录信息，也不运行目标脚本。

AWS 控制台及可识别的 Komari 页面有核实的官方图标回退。登录限制、动态图标或禁止抓取的站点可能仍需手动选择。

彩色目录包含 58 个 Fluent Emoji 和 329 个 Icons8 Flat Color，共 387 个 SVG。[来源与许可](../../public/portal-icons/SOURCES.md)。

## 主题与收藏

主题菜单带中文说明与英文名称。当前主题优先，收藏随后；☆/★ 切换收藏。已登录云端部署将收藏同步到 KV，其他设备刷新或重新读取收藏后显示更新。

主题收藏同步不代表所有浏览器偏好实时同步。主题、布局等按对应设置处理；像素机甲标识随主题样式变化。

## 小组件

在分类下点击 **添加小组件**，查看类型的中文说明并填写所需参数。保存预览后再保存到云端。

- 时钟读取设备时间，时区可用 `Asia/Shanghai`。
- 天气需 OpenWeather API Key，支持城市/坐标，温度保留一位小数。
- RSS、日历和监控类组件需要相应接口或服务。
- 服务端密钥放 CF Secrets，支持的代理可解析 `DASHY_` 占位符。
- 类型已恢复不代表外部服务已部署；加载失败先核对数据源与授权。

## 探针与多页面

HTTP 按响应状态码显示状态，可指定检测地址和额外接受码。HTTP 和 Ping 是独立检测，同时开启可出现两个状态点；Ping 需主机后端。HTTP 成功不代表已完成登录或所有业务正常。

创建 `work.yml` 等独立页面，可分别编辑并保存，子页面保存不覆盖总站。YAML 导出可用于备份；分享前移除私人网址、Cookie、Token 和授权头。
