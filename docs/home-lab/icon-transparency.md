# 图标透明化与清晰度

## 内置品牌图标

主流网站的图标改为透明背景的官方矢量标志，由 `scripts/sync-brand-icons.mjs` 从 simple-icons（CC0）生成到 `public/portal-icons/brand/`。来源与授权见 `public/portal-icons/SOURCES.md`。

- 单色标志（ChatGPT/OpenAI、GitHub、X、Speedtest、TikTok 音符）用 CSS 遮罩绘制，颜色跟随主题文字色：深色主题为浅色，浅色主题为深色。此前 ChatGPT 和 DeepSeek 为了在深色主题可见而加的白底已移除。
- 彩色标志保持品牌色：DeepSeek 为官方蓝色，Google 为四色 G，Instagram 为渐变。Telegram、Reddit、Emby 在镂空处垫白色，Spotify 垫黑色，与官方图形一致。
- 原 QX 圆形徽章（108px 位图）保留在 `qx/`，DMIT、GlobalSpeed、海獭、RN-VPS、月兔仍使用它们。

## 网站自身图标

自动读取或手动填写的位图图标（PNG/JPG/ICO/WebP），会在浏览器中做一次背景透明化：

1. 只处理边缘是均匀浅色的图标。照片、头像、彩色应用方块、本身已透明的图标和 SVG 不处理。
2. 从边缘向内去除相连的浅色背景，Logo 内部的白色保留，边缘柔化并去掉白色残影，再裁去空白边距。
3. 去底后如果是深色单色 Logo，改为跟随主题文字色，避免在深色主题中消失。
4. 处理在一个共享的 Web Worker 中进行。Worker 按需创建，空闲 20 秒后关闭；不支持 OffscreenCanvas 的浏览器在主线程处理。
5. 结果以小尺寸 data URL 缓存在内存中，最多 256 张，不写入浏览器存储。下载失败不缓存，下次挂载时重试。
6. 只能处理同源图片。云端登录模式下图片经 `/api/icon-image` 代理，可以处理；直接跨域加载的图片保持原样。

首次显示时，卡片最多等待 350ms 让透明版本就绪，避免先闪一下白底；超时则先显示原图，处理完再替换。空闲预热会把其他分类的图标一并处理好，切换分类时直接显示最终结果。

## 清晰度

网站读取图标时的候选排序改为：矢量图优先，其次是声明尺寸最大的位图（`sizes="any"` 视为 512）。未声明尺寸的 `apple-touch-icon` 按 180px 计，未声明尺寸的 `rel="icon"` 按 32px 计。此前 `rel="icon"` 固定加分，导致 16/32px 的 favicon 总排在 180px 图标前面。已保存的图标地址不会自动改变，可用编辑弹窗的「读取当前网站图标」或「补齐图标与说明」重新读取。

## 限制

- 深色的彩色文字 Logo 去掉白底后，在深色主题中的对比度会降低。
- 横向文字 Logo 按方形区域显示，字会偏小。
- 浅色背景上的浅色 Logo（如白底浅灰标志）可能被判断为没有可保留的内容，此时保持原图。
