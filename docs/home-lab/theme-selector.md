# 主题菜单配色分支

分支：`fix/theme-menu-colors-20261018`，基于 `master` 的 `b5ac060`。此说明记录分支方案，不代表已部署。

原菜单只为 `button:hover` 设置蓝色底色；主题选择和收藏是两个并排按钮，因此名称区域高亮时星标区域仍保留原底色。本分支将交互背景移至整行，按钮自身保持透明，选中与悬停均覆盖整行，圆角统一。键盘 Tab 聚焦任一按钮时也会高亮整行，实际焦点按钮保留内侧边框。

菜单使用当前主题的设置面板底色与强调色，生成不透明背景、轻强调悬停色和更明显的选中色。普通/次要文字、星标与输入框文字目标对比度为 4.5:1；边框目标为 3:1。选中或悬停行的英文名称、当前标识和星标继承该状态的文字颜色。透明设置面板先与页面底色叠加，避免后方网站卡片干扰阅读。

窗口主题或自定义颜色变化时，复用现有主题颜色观察机制重新计算菜单配色。不修改主题保存、共享配置、收藏请求及前一版本的专注卡片交互。

## 验证

```bash
node --test tests/theme-menu-palette.test.mjs
npm run build
```

自动检查使用真实 Sass 配色，覆盖 54 个内置主题的普通、悬停、选中、次要文字、星标和边框对比度。DOM 模拟的颜色格式归一化工具位于 `scripts/lib/theme-audit-dom.mjs`。这属于颜色计算验证，不代表已完成真实浏览器布局、字体和帧率验收。

视觉复核：文档蓝、原版质感浅色、粗野主义、羊皮纸、深色主题；鼠标经过主题文字、当前标识与右侧星标时均整行高亮；Tab 分别聚焦选择和收藏；搜索、滚动、触屏点击与收藏后排序。此分支不更改生产主题供测试。
