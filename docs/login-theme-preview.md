# 登录页主题分支预览

分支：`feat/login-theme-preview`。本分支不改变生产域名或密码验证规则，未经确认不合并至 master。

登录界面复用总站的像素高达、内置主题和内容卡片底色。背景加入由主题强调色生成的柔和色光；浅色主题不再把深色导航栏用作整块表单底色。主题名称和同步说明已从登录内容中删除。顶部“登录设计”、主题选择及手机按钮仅位于独立预览文件，不进入实际部署的登录组件。

## 电脑和手机使用同一主题

云端 Home Lab 使用总站根配置中的 `theme` 和 `customColors`，登录页、登录后的主页与分页面均以这份配置为准。旧浏览器保存的主题或配色、分页面的旧主题不会覆盖它；云端模式不按各设备操作系统分别选择日夜主题。

在正常浏览模式的主题选择器中选择内置主题，会通过需要管理员登录的 `PATCH /api/theme` 保存云端，成功后应用；失败时保留原主题并提示重试。自定义配色的保存和重置也使用同一接口。只更新外观字段并保留书签等其他内容，保存前仍按既有机制自动备份。编辑模式下选择主题仍属于编辑草稿，需要正常保存配置。

登录页在打开、切回页面及可见期间每 15 秒读取外观；已登录页面在切回及可见期间每 30 秒刷新配置，编辑或弹窗打开期间不替换草稿。Cloudflare KV 的跨地区传播可能额外延迟，因此此方案提供最终同步，不承诺同一毫秒切换。

`GET /api/login-appearance` 只返回受限的主题标识和安全颜色。完整配置、书签、说明、字体或外部样式地址仍要求管理员登录。外观读取失败不阻止密码表单使用。非云端 Dashy 的本地主题行为不变。

## 生成独立预览

安装项目依赖后运行：

```bash
node scripts/build-login-preview.mjs /tmp/HomeLab_Login_Theme_Preview.html
```

在浏览器打开生成的 HTML，切换顶部主题列表和“手机预览”。预览由真实 CloudLogin 组件生成，页面内拦截所有请求，不连接服务器，也不提交密码。主题按钮模拟云端返回值；独立文件不验证两台真实设备的云端同步。字体缺失时回退到中文无衬线字体。预览内置像素高达资产，可以离线打开；可通过 `LOGIN_PREVIEW_ASSETS` 指定缩小后的同名 PNG 以减小文件体积。

预览的 Vite library 模式显式替换 `process.env.NODE_ENV`，避免浏览器缺少 Node 全局变量导致空白。`node --test tests/login-preview-artifact.test.mjs` 会生成并执行最终 HTML 中的组件包，也可通过 `LOGIN_PREVIEW_HTML` 指定已有生成文件。

## 验证范围

自动检查涵盖匿名接口过滤与权限边界、跨设备读取同一已保存主题、旧缓存与分页面覆盖、云端保存失败、配置历史和书签保留、登录成功/错误、重新聚焦刷新、预览挂载及 54 个内置主题的颜色解析与文字对比度（正文 4.5:1、聚焦轮廓 3:1）。颜色检查使用 DOM 模拟环境，补齐该环境将浏览器 rgb 计算值保留为 hex 的差异；不将它等同于真实渲染验收。

生产与独立预览构建通过。当前连接浏览器无法访问工作环境 localhost，真实浏览器布局、真机双端云端传播和 iPhone Safari 仍待验收。
