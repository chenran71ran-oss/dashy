# Home Lab 图标与主题

主页、工作台侧栏、编辑预览共用同一个图标渲染组件。已有自定义图片地址保持有效；旧占位图标的品牌匹配也在各视图一致显示。

编辑网站时：

- **自动匹配图标**：先匹配本地 QX/品牌图标，再读取公开网站首页声明的图标，最后尝试 favicon 和首字。自动匹配不会更改网站地址。
- **读取当前网站图标**：重新请求该网站首页声明的图标，并写入当前编辑草稿；需要保存网站并保存配置后才持久生效。它可覆盖草稿中的手动图标，取消编辑不会保存。
- **选择图标**：QX/品牌、服务器与网络、安全、开发、影音、办公、心情、自然、兴趣和工具分类。新增 **彩色图标** 分类，可直接查看 58 个 Fluent Emoji 与 329 个 Icons8 Flat Color，共 387 个彩色 SVG；它们也按用途出现在原有分类中。支持中文分类、常用中文名称与英文关键词搜索、分批加载。不依赖访问 GitHub 来显示本地图标。

读取功能仅访问公开 HTTPS 网站首页，不携带浏览器 Cookie，不提交网站地址中的路径或参数。需要登录的网站、拒绝抓取的网站可能只能得到 favicon；失败时仍可选择本地图标。

主题菜单显示中文描述与原始英文名称。每次打开时当前主题在首位，收藏主题随后排列。☆/★ 切换收藏；收藏保存在当前浏览器，未同步到 Cloudflare KV。自定义主题继续使用原有调色板入口。

**专注**是简化导航视图：保留搜索、分类及网站入口，减少小组件干扰；没有计时器，也不会屏蔽其他网站。**工作台**额外提供侧栏和原版的网页/小组件工作区域。外部网站是否允许嵌入仍取决于该网站；新标签页打开选项继续有效。

第三方图标来源及完整许可证见 `public/portal-icons/SOURCES.md` 和各图标包的 `LICENSE`。
