# Home Lab 图标与主题

主页、工作台侧栏、编辑预览共用同一个图标渲染组件。已有自定义图片地址保持有效；旧占位图标的品牌匹配也在各视图一致显示。

编辑网站时：

- **自动匹配图标**：先匹配本地 QX/品牌图标，再读取公开网站首页声明的图标，最后尝试 favicon 和首字。自动匹配不会更改网站地址。
- **读取当前网站图标**：先使用已核实的本地官方品牌图标，否则读取当前网址路径的公开元数据，移除查询参数与片段，支持相对图标、base 地址与 PWA 清单；写入当前编辑草稿，保存到云端才持久生效。失败时保留原图标，取消编辑不会保存。
- **选择图标**：QX/品牌、服务器与网络、安全、开发、影音、办公、心情、自然、兴趣和工具分类。新增 **彩色图标** 分类，可直接查看 58 个 Fluent Emoji 与 329 个 Icons8 Flat Color，共 387 个彩色 SVG；它们也按用途出现在原有分类中。支持中文分类、常用中文名称与英文关键词搜索、分批加载。不依赖访问 GitHub 来显示本地图标。

自动模式读取公开首页；主动读取按钮可访问当前路径。两者不转发总站 Cookie 或第三方登录凭据。需要登录或限制抓取的网站可能无法读取；可选本地图标。NodeSeek 和 DeepSeek 使用本地官方品牌图标，DeepSeek 的单色轮廓随主题文字颜色显示。AWS 控制台与可识别的 Komari 页面有核实的官方图标回退。HTTP 403 会明确提示服务器读取被拒绝，而不会说成网站没有图标；首字母只作为加载失败的占位显示。

主题菜单显示中文描述与原始英文名称。当前主题在首位，收藏随后。☆/★ 切换收藏；已登录云端部署将收藏同步到 Cloudflare KV，本地缓存用于界面读取，其他设备刷新或重新读取后获得更新。自定义主题继续使用调色板入口。

**专注**是分类聚焦视图，显示当前分类的网站与小组件；没有计时器，也不会屏蔽其他网站。**工作台**提供侧栏和网页/小组件工作区域。外部网站是否允许嵌入取决于该网站，新标签页打开选项继续有效。

第三方图标来源及完整许可证见 `public/portal-icons/SOURCES.md` 和各图标包的 `LICENSE`。
