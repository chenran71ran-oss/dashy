# 登录界面主题联动分支

目标：保留 Home Lab 像素高达身份，使登录页使用总站的主题配色，并在独立分支提供桌面和手机预览。生产 master 和域名配置保持不动。

主题来源：当前域名浏览器保存的有效主题优先，其次云端日夜主题和主主题，最后 nord-frost。复用现有主题样式，支持内置主题及其中经过校验的自定义颜色。登录前不加载任意外部样式、自定义脚本或背景 URL。

外观接口仅返回主题、日夜主题及有限颜色；完整网站列表、页面信息、令牌和配置继续要求登录。接口不可用时仍显示表单。

界面：桌面左侧品牌和像素高达，右侧单字段表单；700px 以下单列，紧凑品牌区。保留现有 POST /api/login 和 authenticated 事件。加入密码显示控制，输入框与主按钮不少于 50px，验证文本和按钮对比度。

测试：匿名外观接口投影与权限边界、浏览器主题优先、云端主题回退、错误及成功登录；桌面/手机宽度和浅深彩色主题检查。独立 HTML 预览使用真实组件，但在预览页内拦截网络，不校验或发送真实密码。

交付：独立 Git 分支、可下载的主题/尺寸切换预览及截图。未经后续授权不合并生产。
